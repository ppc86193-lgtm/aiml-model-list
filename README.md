# AIML Model List

A service to retrieve and display AI model lists from AIML API.

## Overview

This project provides a clean interface to access AI model information from the AIML API service, including model names, developers, descriptions, context lengths, and supported features.

## API Reference

- **Endpoint**: `GET https://api.aimlapi.com/models`
- **Response**: JSON object containing array of model data
